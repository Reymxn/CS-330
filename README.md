# CS 330 Final Project - Rocket Launch Scene

## Overview

This project is a 3D rocket launch scene created using OpenGL and C++. The scene demonstrates concepts learned throughout CS 330, including 3D modeling, textures, lighting, transformations, materials, and camera controls. The environment features a rocket on a textured launch surface with a nighttime sky, moon, and stars.

---

Reflection

## 1. How do I approach designing software?

This project helped me develop stronger software design skills by teaching me how to build a complex scene from smaller, reusable components. I designed my rocket by combining basic 3D primitives such as cylinders, cones, and planes instead of trying to create one large model. I also organized my code into separate functions for rendering, transformations, lighting, and texture management, which made the project easier to maintain and debug.

The design process I followed was iterative. I started with a simple rocket and ground plane, then gradually added textures, lighting, the moon, stars, and camera controls over multiple milestones. Testing each addition before moving on allowed me to identify problems early and make improvements throughout development.

In future projects, I will continue using this step-by-step approach because it keeps large projects organized, makes debugging easier, and allows new features to be added without disrupting existing code.

## 2. How do I approach developing programs?

While developing my 3D rocket scene, I learned several new programming strategies related to computer graphics. I gained experience working with OpenGL to create 3D objects, apply textures, configure multiple light sources, perform object transformations, and implement camera movement. I also learned how important modular programming is by separating different responsibilities into functions such as scene preparation, rendering, lighting setup, and texture loading.

Iteration played a major role in my development process. Throughout the project I repeatedly tested my scene, adjusted object positions, refined the lighting, replaced textures, and improved the environment by adding a moon and stars. I also spent considerable time troubleshooting issues such as textures not loading correctly and lighting not producing the desired appearance. Solving these problems strengthened both my debugging skills and my understanding of the graphics pipeline.

My approach to programming evolved throughout the milestones. Early on, my focus was simply getting objects to appear correctly. As the project progressed, I became more focused on creating a polished scene by improving realism, organization, lighting, materials, and user interaction through camera controls.

## 3. How can computer science help me in reaching my goals?

This project expanded my understanding of computational graphics and visualization by giving me hands-on experience with concepts such as 3D modeling, transformations, textures, lighting, materials, and camera navigation. These skills have strengthened my overall programming knowledge and introduced me to an area of computer science that combines technical problem solving with creativity.

From an educational perspective, this experience has improved my ability to analyze problems, debug complex programs, and understand how different graphics systems work together to create an interactive 3D environment.

Professionally, the skills I gained can be applied to software engineering, game development, simulation, and visualization projects. Learning OpenGL and C++ has given me a stronger foundation in graphics programming and has improved my confidence in building larger, more complex software applications in the future.
